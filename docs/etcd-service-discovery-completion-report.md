## 核心技术点

### 1. 服务注册机制
- go-zero 使用 Etcd 租约（Lease）机制
- 服务启动时自动注册，定期续约
- 服务停止或异常时，租约过期后自动注销
- 注册格式：`{ServiceKey}/{LeaseID}` → `IP:Port`

### 2. 服务发现机制
- 客户端通过 Watch 机制监听服务列表变化
- 内置负载均衡（轮询、随机等）
- 实例上下线时自动更新服务列表

### 3. 配置变更示例

**服务端（RPC 服务）**：
```yaml
# 添加 Etcd 注册配置
Etcd:
  Hosts:
  - 127.0.0.1:2379
  Key: user.rpc
```

**客户端（Gateway/其他 RPC）**：
```yaml
# 从硬编码改为服务发现
UserRpc:
  Etcd:
    Hosts:
    - 127.0.0.1:2379
    Key: user.rpc
  NonBlock: true
```

## 使用指南

### 本地开发
```bash
# 1. 启动 Etcd
etcd

# 2. 启动所有服务（自动注册）
scripts\start-all.ps1

# 3. 验证服务发现
curl http://127.0.0.1:8080/api/v1/counter/knowpost/123
```

### 多实例部署
```bash
# 启动第一个实例（默认配置）
./bin/counter-rpc.exe -f services/counter/rpc/etc/counter.yaml

# 启动第二个实例（不同端口）
./bin/counter-rpc.exe -f counter-rpc-2.yaml
```

### 生产环境配置
```yaml
Etcd:
  Hosts:
  - etcd-node1:2379
  - etcd-node2:2379
  - etcd-node3:2379
  Key: user.rpc
```

## 风险与注意事项

1. **Etcd 依赖**
   - 所有服务依赖 Etcd 可用性
   - Etcd 故障会导致新服务无法注册
   - 已注册的服务会继续使用本地缓存的服务列表

2. **网络要求**
   - 服务实例之间需要网络互通
   - 服务与 Etcd 之间需要网络互通
   - 防火墙需开放相应端口

3. **时钟同步**
   - 多实例环境建议配置 NTP
   - 避免租约时间计算错误

4. **向后兼容**
   - 配置文件保持向后兼容
   - go-zero 同时支持直连和服务发现两种模式
